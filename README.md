# qmetro

Subways and metros - QT5 conversion

Abandoned QT4 program forked from http://pmetro.su/ to vibe-convert into QT5.

![qmetro.png](https://i.postimg.cc/QxVwsq5F/qmetro.png)](https://postimg.cc/vcF3tf0y)

Subway maps for searching stations and calculating routes. About 200 maps  are available. Maps have an open format and can easily be edited or created. And you can download maps from within the app if the package missed any.
